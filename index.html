CO2-Emissionen weltweit

Kohlendioxid entsteht vor allem beim Verbrennen von Kohle, Öl und Gas und ist der wichtigste Treiber des Klimawandels. Die folgende Tabelle zeigt, wie viel CO2 verschiedene Unternehmen in unterschiedlichen Ländern pro Jahr ausstoßen. Über die Filter und einen Klick auf die Spaltenköpfe lassen sich die Daten gezielt vergleichen.

Datenschutzhinweis

Dieser Hinweis ist ein Muster im Rahmen eines Studienprojekts.

Keine Erhebung personenbezogener Daten

Diese Webseite setzt keine Cookies, verwendet kein Tracking und speichert keine Eingaben. Die Filterfelder werden ausschließlich im Browser verarbeitet.

Hosting

Die Webseite wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse, um die Seite auszuliefern.

Externe Bibliotheken

Bootstrap und Vue.js werden über das Content Delivery Network jsDelivr geladen. Dabei wird die IP-Adresse der Besuchenden an den Anbieter übertragen.
